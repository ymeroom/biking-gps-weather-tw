騎乘前必讀 · 台灣版

單車 GPS 降水地圖
使用手冊

騎車時打開的手機網頁：藍點跟著你的 GPS 走，地圖疊上中央氣象署的雷達回波圖，讓你在路上目測「等一下這場雨會不會掃到我」。

定位：±12 m 雷達：Rainbow 預報 速度：21.4 km/h

▲ 這是 App 頂端的三個狀態標籤，開起來就會看到。

01這是什麼、不是什麼

日本版（biking-gps-weather）用氣象廳免費的「未來 2 小時雷達預報圖磚」。台灣沒有免費公開的等價資料——中央氣象署只有觀測回波、沒有未來。

所以台灣版改用 Rainbow Weather（衛星＋雷達的 AI 預測，有付費 API 但免費額度個人用足夠）：時間軸能往未來播 2 小時，看雨帶預測往哪移動；降雨面板直接告訴你「你的位置大約幾分鐘後開始下雨」。Rainbow 掛掉時自動退回氣象署觀測回波（就只剩過去、沒有未來）。

要有心理準備

未來那段是 AI nowcast：前 30–60 分鐘可信，往後越久越「糊」，超過 90 分鐘只能當趨勢參考（App 會標「僅供參考」）。它不是氣象署官方等級，但台灣衛星覆蓋很好，實務上夠用。

02第一次使用

這四步是有順序的，照做一次之後每天點 icon 就能開。

  1. 手機瀏覽器開網址iPhone 用 Safari、Android 用 Chrome，開 ymeroom.github.io/biking-gps-weather-tw。定位功能只在這種 https 網址下有效，直接雙擊本機檔案（file://）會被瀏覽器擋。
  2. 允許定位權限跳出詢問時選「允許」。建議選「使用 App 期間允許」＋「精確位置」，藍點才會準。
  3. 加到主畫面Safari 分享鈕 →「加入主畫面」；Chrome 選單 →「加到主畫面」。之後點 icon 全螢幕開啟，跟 App 一樣。
  4. 帶行動電源持續定位 + 螢幕開著很吃電。長程騎乘一定要帶。

03畫面上有什麼

藍點＋三角
你目前的位置與行進方向。外圈淡藍色是定位精度，圈越大代表越不準（常見於室內、高樓、剛開 GPS 時）。
橘色虛線點
照你現在的方向與速度直線推算的前方位置，標 +10／+20／+30 分與距離。拿它去對雷達回波：「我到那裡的時候，雨帶到哪了？」靜止或手機還沒回報方向時不顯示。
時間軸＋▶
過去 1 小時 ＋ 現在 ＋ 未來 2 小時，每 10 分鐘一格。按 ▶ 播放看雨帶預測怎麼移動。時間標籤會寫「觀測」或「+40 分 · 預報」；超過 90 分鐘標「僅供參考」。（退回氣象署觀測時就只有過去。）
降雨面板
畫面最上方那條。頭條是 Rainbow 對你實際位置的預測：「約 25 分鐘後開始下中雨」或「未來 2 小時無雨」。第二行是氣象署縣市級3 小時降雨機率（背景參考，跟雷達不同尺度別混用）；縣市資料過期會標「⚠️ 資料過期」。
雷達來源標籤
頂端標籤，寫目前用哪個源：Rainbow 預報（正常）／08:30 CWA觀測（Rainbow 掛了退回氣象署）／RainViewer後備（再退一層）。App 每 3 分鐘重讀。
📍 跟隨
亮起時地圖自動跟著藍點跑。手動拖動地圖會自動關掉，方便你先看遠處的雨。
⏱️ 回到最新
時間軸一鍵跳回「現在」那一格（不是最未來那格）。
💡 螢幕常亮
騎乘時不讓螢幕自動關。iOS Safari 沒有這個功能，按鈕會顯示「不支援」—— 請改到 iPhone 設定 →「螢幕顯示與亮度」→「自動鎖定」調長或設「永不」。
🌙 深色底圖
把街道底圖反轉成暗色，傍晚或夜騎時回波看得比較清楚、也比較不刺眼。

04雷達怎麼看

Rainbow 預報（正常情況）：藍→靛→紫的強度漸層，越深＝雨越大。

淡藍毛毛雨 / 小雨
藍小雨 → 中雨
深藍中雨
靛大雨
藍紫大雨 → 豪雨
紫劇烈

退回氣象署觀測時：dBZ 標準色階（藍=小雨 綠=中雨 黃=大雨 紅=豪雨 紫=劇烈）。App 的「🎨 圖例」會跟著目前的源自動切換。

判讀重點

播完整段看移動。按 ▶ 播過去→未來，注意雨帶整體往哪個方位飄、大概多快。台灣夏天午後雷雨常從山區往平地、或隨西南風由西南往東北移。

對照橘色推算點。看你 +30 分 的推算位置，落在未來影格的雨帶裡嗎？那就是「我到那裡時大概會遇到雨」。

深色 / 大雨不要硬騎。靛紫色預報回波往往伴隨強陣風、能見度驟降、甚至落雷。提早找地方躲。

預報會變。AI nowcast 每 10 分鐘更新一次，雨帶可能發展也可能散掉。90 分鐘後的影格只能當趨勢。

05實用建議

  • 出發前：把時間軸從過去播到未來一次。面板頭條說「未來 2 小時無雨」、未來影格也沒有雨帶往你路線方向來 —— 通常可以放心出門。
  • 騎乘中每 15–20 分鐘瞄一次：停紅燈、補給、上廁所時看就好。重點是面板頭條有沒有變成「約 X 分鐘後開始下雨」。
  • 面板說要下雨時：播未來影格，看橘色 +30 分 推算點落在哪。推算點在未來的雨帶裡、雨帶還在往你這邊移 —— 大概躲不掉，提早找超商 / 騎樓 / 加油站。
  • 雨帶跟你同向移動：如果回波移動方向跟你前進方向差不多、速度也接近，你可能會「跟著雨走」很久。考慮放慢讓它先走、或加速切出去。
  • 山區 / 縱谷路線：地形雨變化快，縣市級文字預報參考價值低，以雷達回波的實際發展為準。
  • 傍晚 / 夜騎：先開 🌙 深色底圖。iPhone 記得把「自動鎖定」設長一點，Android 開 💡 螢幕常亮。
  • 沒有手機訊號時：地圖底圖和回波都是網路載入的，山區收訊差就刷不出來。進山前先在有訊號的地方把最新回波載好、心裡有個底。
  • 別完全信推算點：它假設你直線前進、等速。實際會轉彎、爬坡變慢、下坡變快。把它當「大概那個方向那個距離」，不是精準預言。

背後怎麼運作

Rainbow 的 API 金鑰不能放進網頁原始碼（超量會計費），所以中間隔一個 Cloudflare Worker 代理：網頁打 Worker、Worker 拿著金鑰去打 Rainbow、只放行本站來源。氣象署那條走 GitHub Actions 排程抓圖存分支，當 Rainbow 掛掉時的後備。

07已知限制

  • 未來預報是 AI nowcast，不是氣象署官方。前 30–60 分鐘可信，90 分鐘後越來越糊（App 標「僅供參考」）。台灣衛星覆蓋好，實務夠用，但別當聖旨。
  • Rainbow 掛掉就沒有未來。退回氣象署觀測時，時間軸只剩過去，靠自己外推。看頂端標籤確認目前用哪個源。
  • 縣市降雨機率是「文字預報」不是雷達。縣市級、每 3 小時一格、約 6 小時更新。跟上面的雷達時間尺度完全不同，別混用。
  • 剛開 App 時橘色推算點可能不出現。手機要持續移動幾秒才會回報行進方向和速度。App 會顯示一行說明。
  • iOS Safari 不支援螢幕常亮。用系統設定的「自動鎖定」替代。
  • 推算點是直線等速。實際會轉彎、爬坡變慢。當「大概那個方向那個距離」，不是精準預言。
